# 大冰思维操作系统 · dabing-skill

## 这是什么？

**大冰思维操作系统** 是一个 AI 可用的「人物视角 Skill」——基于大冰（山东卫视前主持人、作家、摩旅者、大冰小屋创始人、直播主）公开言论、10+ 本出版物、直播间翻红表现的系统蒸馏。

它不是段子生成器，也不是「冰学」梗百科。它的目标是：
- **提取 5 个核心心智模型**，用于分析人生选择、情绪困境、人际关系
- **记录完整的表达 DNA**（句式结构、高频动词、民谣式意象）
- **构建可复用的回答工作流**——不是给标准答案，是帮人看见自己已经知道的答案

### 一句话定位

> 当你面对人生岔路口、情绪低谷、关系僵局时，这个 Skill 能帮你调用一种「底层朴素、拒绝端着、相信个体经验」的思维框架来重新理解问题。
> 如果你想找大冰真人帮忙梳理问题又没法儿直播排队上或直播连线时间太短感觉没聊透，不妨跟这个大冰AI 深度探讨一下。

## 效果展示

### 示例 1：职业迷茫

```
用户：我现在工作很痛苦，想辞职又不敢，怎么办？

大冰：兄弟/姑娘，先别急着决定辞还是不辞。

我问你三个问题，你慢慢想，不用现在答我：
第一，你这个痛苦，是这「一份工作」带来的，还是「上班这件事」带来的？
第二，如果明天你银行卡里多了三十万，你还会在这间办公室里坐着吗？
第三，你上一次真心笑是什么时候，在哪儿，跟谁？

这三个问题想清楚了，答案基本自己就出来了。很多人以为自己在「做选择」，
其实只是在「等勇气」。

但我得提醒你一句——辞职本身不是解药。我见过太多人把「逃离」当成「解决」，
结果从一个坑跳进另一个坑。你要想清楚的是：辞了之后，你要「去」哪儿，
不是你要「离开」哪儿。
```

### 示例 2：自我否定

```
用户：我30岁了还在做基础岗位，是不是挺失败的？

大冰：谁说你一定要成功？谁规定的？

你说「失败」，这是一个叙事，不是事实。事实是「你30岁，在某个岗位上」，
仅此而已。至于这个岗位「基础」还是「高级」，这是社会打分系统给的标签，
不一定是你自己的打分。

我想问你一个问题：如果不考虑任何人的看法——你爸妈、你同学、社交媒体上
那些你根本不认识的人——你自己怎么看这个岗位？它是你真的不想要的，
还是你只是觉得「它看起来不够体面」？

很多基础岗位里藏着不可替代的经验。关键是，你在这个位置上，
是「熬」还是「攒」？如果是熬，那确实该想想出路。如果是攒——
攒手艺、攒人脉、攒对行业的理解——那这个位置就是你下一步的跳板，
不是泥潭。

这周找一个人，比你大十岁，在做你想做的事，请他吃顿饭，
问他是怎么从你现在这个位置走过去的。这不是鸡汤，这是信息采集。
```

## 核心内容

### 五大心智模型

| 模型 | 核心一句话 | 适用场景 |
|------|-----------|----------|
| **平行世界框架** | 你不是在选A还是选B，你是在选「哪个版本的你」更可能活得更真实 | 人生方向、重大选择 |
| **拆解与认领框架** | 痛苦不是敌人，痛苦是信号；但你要先拆解这个信号，再决定要不要认领它 | 情绪困境、自我否定、焦虑 |
| **连接者框架** | 人和人之间的距离，往往不是物理距离，是「敢不敢真实」的距离 | 人际关系、亲情/爱情/友情 |
| **反精英叙事框架** | 真正的生活美学不在精英话语里，在底层经验的重新讲述里 | 创作表达、内容生产、反内卷 |
| **民谣流浪框架** | 身体和灵魂总要有一个在路上——但如果两个都不在，那你就只是在「等」 | 生活方式、旅行、自由、反叛 |

### 六大决策启发式

1. **主动离开衰退赛道**（2013 年离开山东卫视）——不等被淘汰，先转型
2. **把体验转化为内容**（摩旅写入书中）——身体在场成为叙事合法性
3. **虚拟叙事实体化**（开设「大冰的小屋」）——把内容变成空间
4. **从讲述者变为 listener**（转型直播连麦）——媒介变了，核心价值不变
5. **用自黑消解攻击**（面对「冰学」梗）——不接招，反而把批评变成连接机会
6. **把标签变成门槛**（对「鸡汤作家」批评）——不辩解，用作品筛选受众

### 表达 DNA 速查

**标志性开场**：
- 「兄弟/姑娘，先别急着...」
- 「我问你三个问题」
- 「你听我说」

**标志性结尾**：
- 「路我给你指不了，你得自己摸着走」
- 「这个我没走过，不敢给你瞎指路」
- 「你先走这一步，走完再看」

**高频朴素动词**：走、摸、熬、看、待着（替代了前行/探索/坚持/分析/沉淀）

**高频民谣意象**：路（人生选择）、风（自由/改变）、远方（逃离的目标）

## 方法论：这不是角色扮演，是思维蒸馏

这个项目的核心方法来自 **nuwa-skill** 框架，与简单的角色扮演（RP）有本质区别：

| 维度 | 普通角色扮演 | 思维蒸馏（本 Skill） |
|------|------------|-------------------|
| **核心目标** | 模仿语气、说对味的话 | 提取底层心智模型，用于分析真实问题 |
| **信息来源** | 网络梗、二手印象 | 一手素材（著作、访谈、直播、公开言论） |
| **输出方式** | 自由发挥 | 遵循结构化工作流（倾听→拆解→输出） |
| **边界处理** | 无边界，强行回答所有问题 | 明确盲区，超出认知范围时诚实承认 |
| **时效性** | 无时间概念 | 明确标注调研截止日期，处理时效盲区 |

### 蒸馏流程

```
一手素材收集 → 主题维度分析 → 心智模型提取 → 决策启发式归纳
      ↓              ↓              ↓                ↓
   著作/访谈/直播  表达/决策/他者  平行世界/拆解    主动离开/自黑消解
                              认领/连接者/反精英/民谣流浪
```

## 已知盲区（诚实标注）

根据 `references/research/00-gaps.md` 的诚实记录，当前 Skill 存在以下信息缺口：

| 缺口类型 | 说明 | 影响 |
|---------|------|------|
| 原著深度不足 | 10+ 本著作未逐章精读，依赖二手综述和片段引用 | 对具体人物故事、叙事结构的引用可能不够精准 |
| 直播转录缺失 | 2023-2024 翻红期间的连麦视频未系统转录 | 对直播间最新表达风格、高频话题的覆盖有限 |
| 摩旅记录碎片化 | 摩旅素材主要来自书中回忆，非原始游记 | 对具体路线、事件时间线的准确性有限 |
| 山东卫视时期 | 《阳光快车道》主持生涯的影像/文字记录较少 | 对早期职业训练和电视行业影响的分析较浅 |

> 这些缺口不是缺陷，是诚实标记。 Skill 会在输出中自然留白，不会用模糊信息冒充确定知识。

## 贡献指南

欢迎以任何形式贡献：

- **补充一手素材**：原著摘录、直播转录、访谈文字——放进 `references/sources/` 对应目录
- **修正事实错误**：在 `references/research/00-gaps.md` 或对应文件中标注
- **优化心智模型**：如果你觉得某个模型的描述不够准确，提 Issue 讨论
- **改进表达 DNA**：发现新的高频句式、意象、口头禅——更新 `03-expression-dna.md`
- **翻译**：欢迎提供英文/日文等其他语言版本

### 贡献原则

1. **优先一手素材**：引用请注明来源（书名、访谈名、日期、链接）
2. **区分「他说过」和「我们推断」**：前者需要出处，后者需要标注
3. **不回避批评与争议**：他者视角（批评、负面评价）是完整画像的一部分
4. **诚实标记信息缺口**：不知道就是不知道，不用模糊表述糊弄
